## 一处需要说明的判断

第一份文件我最初判断为"字节相同的副本"，**这是错的**——加 SHA256 比对后发现两者哈希不同：

```text
root : 288D1F5A28B13AE94D9EAAC500F239AC749D35F8471695514CD4206CD7FF05A3
task : 1F3B0590B32A59445EF90FCE4C68729229B0E8BE8D242842989376CB5D698093
```

逐行 diff 后确认**唯一差异是时间戳**（`16:46:14` vs `16:46:31`，相隔 17 秒），  
其余完全相同：同文件 `14-review-v2.mp4`、同 `task_id: 14`、同 `version: v2`、  
同 `exit_code: 0`、同"full decode clean"结论。属同一次解码检查的两次落盘，  
根目录那份是**更早**的一次，任务目录那份是符合约定的正本。

结论：隔离根目录副本安全。**但这说明"同名同大小"不能当作"是副本"的证据**，  
后续再做同类清理必须比对哈希或内容，不能凭文件名和大小下判断。
