## ⚠ 渲染器的一处修正（v1 → v2 之间发现并修好）

v1 用 `-ss <start> -t <dur>` 切段，**`-t` 会把最后一帧的显示时长算进去**，于是每段都比标称长一丝。16 段累加后容器 `avg_frame_rate` 变成 **59.99995** 而不是 `60/1`，`qa_gate` 的 `frame_rate` 门禁判 **FAIL**。

修法（`cache\render_preview.py`）：改用 **`-frames:v N`**（`N = round(dur × 60)`）决定每段长度，并显式加 `-r 60 -video_track_timescale 60000`；concat 也加同样两项。节目映射仍保留精确到 0.001 s 的十进制边界，**只有渲染帧数取整，每切口最多差 1/120 s**。修后 `avg_frame_rate` 恢复为 `60/1`，门禁通过。
