## 3. 重点核实方向的逐条回答

### 3.1 180–215 是真实交战还是纯跑图+闲聊？→ **真实交战**

不是跑图+闲聊。三重独立证据：

1. **`186` 出现敌方红血条**（`hd\t0186.0.jpg`），已按 §5 要求向前回查至 181，181–185 全部无红条/无伤害数字/无锁定线 → 交战首帧 = 186，不是更早。
2. **`187` 整屏橙红不是位移特效**：该帧同时存在**受伤晕影（红屏）+ 浮动伤害数字 23 / 15**（`hd\t0187.0.jpg`）。转写 187.0「先飛一下」只是玩家在挨打时的位移语音，**不能据此把它当成纯位移**；作业书 §5.1「钩锁/御空类位移特效不得单独作为交战证据」在这里反过来也不成立——因为有伤害数字这一独立硬信号。
3. **`212` 出现伤害数字 410**（`hd\t0212.0.jpg`），`214` 出现**击杀播报横幅**（`hd\t0214.0.jpg`）。

转写在此段只有闲聊（「这游戏 唯一手万灵武术师」「啊?」「我去与同仁游戏」），**按 §5 完全不能作为交战证据**；结论 100% 来自画面三信号。

### 3.2 「哦 起来了」（转写 233.0–243.6）是不是倒地后被救？→ **不是。是被击飞后 1–2 秒自行起身。**

**先说转写本身不可信**：`233.02–243.56` 是同一句「哦 起来了」**连续重复 10.5 秒**，与 `211.10–229.67`「我要打药」（18.6 秒同句）、`245.56–255.53`「OK 太棒了」（10 秒同句）是同一种 faster-whisper **单句幻觉循环**，不能当事件时刻用。真实画面窗口收窄到 239–245 后逐帧核验：

| 秒 | 高清帧显示 |
|---|---|
| 240.0 | 玩家**横躺悬空**（被击飞姿态），长矛外伸，身侧有青色残影与人形，**上方敌方红血条**（`hd\t0240.0.jpg`） |
| 241.0 | 玩家**横卧石地**，相机仍在正常越肩第三人称，**敌方红血条持续**（`hd\t0241.0.jpg`） |
| 242.0 | **玩家已站立持矛向前推进**（`hd\t0242.0.jpg`） |
| 243.0 | 玩家**金色护体、进入再战姿态**，远处人形头顶**清晰红血条**（`hd\t0243.0.jpg`） |

**否定「倒地/救援」的四条依据**：
1. 倒地时长对不上：永劫倒地读条 30–45 秒，玩家 **241 倒地 → 242 已站立**，仅约 1–2 秒。
2. 相机形态对不上：真正倒地时相机会切到贴地低机位并出现救援交互提示；`241` 仍是正常越肩第三人称（`hd\t0241.0.jpg`）。
3. 无复活白光、无队友按 F 救援交互帧；`242` 是玩家自己持矛走出去，不是被扶起。
4. 左下三人小队血条在 240–243 全程无「倒地」标记。

**结论**：`240–241` 是**同一场战斗内的击飞/硬直 + 快速起身**（归入 E3 的 `knockdown` 交战动作），**不构成作业书 §5.1 意义上的「玩家倒地 + 队友来救 + 重新站起来」三段救援链**，因此不需要按救援链单独扩边界；因果链边界就是 E3 内部连续段 `[239.0, 243.0]`，三段（挨击飞 240 / 倒地 241 / 起身再战 242–243）**全部已在 E3 内保留，无遗漏**。
