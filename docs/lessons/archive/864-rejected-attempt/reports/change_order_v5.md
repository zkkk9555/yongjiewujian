## 一、规则变更（本版的根据）

**旧规则（v1–v4，我执行错了）**：按作业书「删：……全屏 UI（除属收束环节的）」，把战斗过程中的背包 / 强化 / 魂玉 / 四栏装备面板当作「待清除 UI」逐块挖除，共 11 处、52.76 s。

**新规则**：在**这个游戏里**，打架中途舔包、换武器、补物资、拿魂玉**本身就是战斗内容**。挖掉它们不是"清理画面"，而是**把一场完整战斗从中间切开**。因此：

> **每一场保留的战斗，必须是从接战到结果的一整段连续画面。**
> **只有在 `outcome_time` 之后的挖除才允许存在** —— 那部分不属于战斗，挖它不会割裂任何一场战斗。

实测后果：v4 的 21 个切口里，**11 个是战斗中途的挖洞**，把 11 场战斗切成了 30 段；`combat_007` 一场就被切成 6 段（25.75 / 2.10 / 3.30 / 27.10 / 17.40 / 5.40 秒），其中 4 个是 6 秒以内的碎片。

## 四、漏战修复：一整场战斗被 v1–v4 删掉了

**`combat_009` 之前只保留源 `[910.99, 943)`。** 而删除段 `[810.0, 910.99)` 里藏着**一场完整战斗，源约 896–908**。

**发现方式**：指挥对 11 条删除段做**语音战斗词扫描**，命中 `904.80–909.34「没事我杀了」`，再用 4K 帧核实。

**佐证**：

| 证据 | 内容 |
|---|---|
| 语音 | `895.97` 我能把他崩死吗 → `897.97` **开始了** → `901.80` **弹太快了** → `904.80` **没事我杀了** → `909.34` 可以来看包了 |
| 4K 帧 | 897 / 899 / 901 / 903 / 905 / 907 = 战斗（紫色特效、近战、伤害数字）；909/911 = 战后走廊 + 舔包面板 |

**为什么七路对抗审 + 四遍自审 + 三路验收全漏了**：它们的任务是「报告保留区间的问题」和「报告本版自身的问题」，**没有任何一个角色被要求去查「被删掉的区间里有没有冤案」**。删除段的 `reason` 写得很详尽（交易、导航、搜刮），但没有任何人用独立的战斗信号去交叉验证它。

**改法**：`combat_009` `source_start` 910.99 → **894.0**，`engage_start` 911.0 → **898.0**；删除段 `[810.0, 910.99)` → `[810.0, 894.0)`。
