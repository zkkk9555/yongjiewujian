**D-1 · `combat_004` / `combat_009` / `combat_010` 三场的 `source_start` 各取 `engage_start − 0.01`**


`start < engage` 是**严格小于**。以处方字面值（`combat_004` 417.0、`combat_009` 911.0、`combat_010` 949.0）实跑 validate，得到：

```

FAILED: episode_009  valid_range=false   (source_start 911.0, engage_start 911.0)

```
