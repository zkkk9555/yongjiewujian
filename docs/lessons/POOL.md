# 待升级经验池（POOL）

> **打开管理窗口时看的就是这一份。** 每条带状态：`待升级` / `已吸收` / `一次性`。
>
> 维护：说一声「**去收纳经验**」，跑 `scripts\collect_lessons.ps1`。
> 它扫出所有经验源里**还没吸收**的条目，并报覆盖率与命名合规。
>
> **三条硬规矩**
> 1. 每条吸收后**必须回填「吸收去向」**——没写去向的不算吸收。
> 2. 「教训」列**以原文标题加粗开头**（**规则级条目适用**）。这是 `collect_lessons.ps1` 的机器锚点：
>    脚本靠它判断某条是否已吸收。改了标题格式就会让已吸收的反复被报成待升级。
>    下面「逐局去向摘要」那组是**记账行**，它的锚点是「来源」列（见第 3 条），
>    「教训」列写的是本局分流结论，不适用本条。
> 3. **来源列写任务目录全名（或专题复盘的文件名）**时，那一份经验源的全部候选一次闭合
>    （脚本的「来源键」机制）。逐局分流结论用这种方式记账；规则级条目另起行、来源写素材号。
>

> 专题复盘原先共用一个 `docs\lessons` 键（**今后新写的专题会被自动算成已吸收**，
