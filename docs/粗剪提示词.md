# 粗剪提示词（通用唯一版）

> 用途：开一个新对话，复制下面 `=== 复制线内 ===` 整段，**只改「素材：」那一行的绝对路径**，然后发送。
>
> **新剪和续剪用同一份**，不需要两套模板：素材已经在 `123\` 下有同编号目录时，它会自动走续剪分支。
>
> 本文件取代早期的 `PROMPT_TEMPLATES_GOAL.md` 与 `PROMPT_TEMPLATES_OPENCODE.md`。

## 设计原则（改这份文件前先看）

1. **薄。** 只写三样东西，别的都不写在这份文件里：
   - **不能猜的**：用户自己的要求、环境入口路径、路径纪律
   - **不该被 skill 覆盖的**：用户意图（「不要问我」「宁可慢不要不能用」）
   - **容易漏掉的机械步骤**：编排契约（状态文件、看门狗、流式合成、授权后自跑）
2. **不复述 skill 的规格。** 剪辑定义、派工角色、门禁口径、判读分辨率**一律不在这里写**——
   它们在 `skills\cujian\references\` 里，且**那边是唯一真源**。
   复述会产生第二份副本，两份不一致就是漂移的根源。**旧版这份文件有 170 行属于这种情况，
   已经删掉**（2026-10-06）。它膨胀的唯一原因是当时 skill 不可见——见下方「为什么曾经很长」。
3. **通用。** 不出现任何 harness 专属接口（`create_goal`、`subagent` 等）。换客户端不用改。
4. **项目工具路径不硬编码。** ffmpeg / python 这类会被重装或挪位的工具，位置以预检输出为准。
   **唯一例外是 Git Bash**（`C:\Program Files\Git\bin\bash.exe`）——它是系统安装的稳定路径，
   写出来是为了让 `.sh` 脚本能被正确调用；这不是漂移源，别当冗余删掉。
5. **唯一允许的重复是看图上限。** 因为违反它不是报错，是整个会话报废，代价太大。
