## 设计原则（改这份文件前先看）

1. **薄。** 只写输入契约、触发语与交付纪律，剪辑规格一律在 `skills\jingjian\references\`。
2. **输入唯一。** 唯一合法输入是冻结粗剪线 + 审片结论，没有冻结版不准开工。
3. **三禁。** 禁挖洞、禁切断、禁回源重选——违任何一条即返工回 cujian。
4. **项目工具路径不硬编码。** ffmpeg / python 位置以预检输出为准。
